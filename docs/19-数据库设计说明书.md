# G05 数据库设计说明书

> 对应国标 GB/T 8567-2006《数据库设计说明书》。本说明书将《详细设计报告》（docs/11）第一节的数据库设计独立成册，供阅卷与后续维护单独查阅。维护者：B1（刘涵）· A（成册整理）。

## 一、数据库选型与运行参数

| 项 | 值 | 设计理由 |
|---|---|---|
| DBMS | SQLite 3.53（WAL 模式） | 零安装单文件；WAL 支持读写并发、崩溃自愈（fault kill 实测 integrity_check=ok） |
| ORM | SQLAlchemy 2.0（Declarative） | 声明式映射 + bulk_insert_mappings 批量性能 |
| 访问参数 | foreign_keys=ON · busy_timeout=5000 · pool_size=10, max_overflow=20 | 外键强制启用；8 线程×40 并发实测无 database is locked |
| 路径 | data/db/g05.db（单文件） | 配置外置（config/*.yaml），随工程目录可携 |

## 二、概念设计（E-R 概览）

```
device 1 ──< point 1 ──< reading
                │
                └──< alarm
lineage（有向边：point/任务/报表节点间）     audit_log（独立 append-only）
```

- 设备—测点：**一对多**（一设备多测点）
- 测点—检测记录 / 告警：**一对多**
- 血缘：测点/报表/任务构成**有向无环图**（BFS 遍历 + 环检测，cycles 必为空）
- 审计：**独立表**记录所有实体变更，append-only

## 三、逻辑设计（7 张表结构）

### 1. device（设备台账）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| device_id | TEXT | **PRIMARY KEY** | 设备编号（业务主键，如 DEV-001） |
| device_name | TEXT | NOT NULL | 设备名称 |
| device_type | TEXT | | 设备类型 |
| location | TEXT | | 所在位置 |
| status | TEXT | | 运行/停止/检修 |
| is_deleted | INTEGER | DEFAULT 0 | **软删标记** |
| deleted_at / version / superseded_by | | | 软删三件套：删除时间 / 版本号 / 被替代指向 |

### 2. point（测点）

| 字段 | 类型 | 约束 |
|---|---|---|
| point_id | INTEGER | PRIMARY KEY |
| device_id | TEXT | NOT NULL REFERENCES device(device_id) |
| point_key | TEXT | UNIQUE NOT NULL（如 FAN0001_VIB） |
| point_name / unit / owner | TEXT | |

### 3. reading（检测记录） / 4. alarm（告警）

均含 `point_id REFERENCES point(id)` 外键 + 时间戳列 + 数值列；复合索引 `ix_reading_point_ts(point_id, ts)`（等值列在前、范围列在后——EXPLAIN 验证命中）。

### 5. lineage（血缘边）

`from_node → to_node` 有向边表 + 唯一约束防重边；**孤儿边=0、自环=0** 由对账脚本恒等验证。

### 6. audit_log（审计，append-only）

| 字段 | 说明 |
|---|---|
| id / ts / operator / entity_type / entity_key | 谁、何时、对哪张表哪一行 |
| before_snapshot / after_snapshot | **改前+改后双快照**（时机：先取改前快照再写库） |
| reason / trace_id | 变更原因 / 全链路追踪 ID |

**防篡改**：触发器 `trg_audit_no_update` / `trg_audit_no_delete` 直接 `RAISE(ABORT)`——绕过应用层也改不了；preflight 自检「触发器缺失即 fail-fast」。

### 7. import_batch（批次声明）

批次声明守恒（对账第五组恒等）：seed 声明条数 ≤ 现存条数，软删不消失。

## 四、外键与级联策略（关键决策）

| 关系 | 策略 | 决策依据 |
|---|---|---|
| point → device | RESTRICT | 设备有测点时禁止物理删除（审计断链风险）→ 改走软删版本链（ADR-002） |
| reading/alarm → point | RESTRICT | 同上 |
| audit_log | 独立表 + 触发器禁改禁删 | append-only 合规要求（ADR-003） |

## 五、索引设计（EXPLAIN 全部命中）

| 索引 | 列序 | 服务查询 |
|---|---|---|
| ix_reading_point_ts | (point_id, ts) | 按设备查时间范围（等值在前/范围在后） |
| ix_checks_device_id | (device_id) | 血缘/明细过滤（EXPLAIN：SCAN→SEARCH 对比见加分项报告） |
| 各表 PRIMARY KEY | rowid 别名 | JOIN 零索引开销 |
