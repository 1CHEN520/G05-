# G05 导入模板说明（业务方版）

> 读者：资产管理员、工艺工程师等准备 Excel 的业务同事。**不需要懂代码。**
> 事实来源：`config/rules.yaml`（C2 维护的校验规则）、`src/g05/api/routes/imports.py`、`src/g05/importers/validator.py`。
> 本文与 `GET /api/import/template` 接口输出保持同步；改 `rules.yaml` 必须同步改本文。

---

## 一、模板从哪来

| 方式 | 操作 | 得到什么 |
|---|---|---|
| 系统接口 | 浏览器打开 `http://127.0.0.1:8000/docs`，找到 `GET /api/import/template` 点 Try it out | 模板字段说明（Markdown） |
| 样例文件 | 找项目组要 `data/sample/sample_devices.xlsx`（由 `python scripts/seed_data.py` 生成） | 可直接参照的 Excel，60 台设备 + 180 个测点 |
| 本文档 | 按下文两张表自己建 | 一个空白模板 |

**工作簿必须包含两个 sheet，sheet 名固定为「设备」和「测点」**（表头名称也必须完全一致，多列/少列/改名列都会直接判失败——严格表头模式，见 `rules.yaml` 的 `strict_header: true`）。

---

## 二、sheet「设备」（5 列）

| 列名 | 必填 | 格式要求 | 示例 | 常见错误 |
|---|---|---|---|---|
| device_code | 是 | 2-4 位大写字母 + `-` + 3-6 位数字；全表唯一 | `FAN-0012` | 写成小写 `fan-0012`；漏横杠 `FAN0012` |
| device_name | 是 | 1-64 字符 | `1号引风机` | 空着 |
| device_type | 是 | 12 选 1：风机/水泵/压缩机/电机/减速机/换热器/锅炉/空压机/输送机/变压器/变频器/冷却塔 | `风机` | 写"离心风机"等枚举外的值 |
| location | 是 | 1-128 字符 | `一厂A区` | 空着 |
| status | 否 | 4 选 1：运行/停机/检修/报废；不填默认"运行" | `运行` | 写"在用"等枚举外的值 |

## 三、sheet「测点」（5 列）

| 列名 | 必填 | 格式要求 | 示例 | 常见错误 |
|---|---|---|---|---|
| device_code | 是 | 必须已存在于设备表，**或与本文件「设备」sheet 同批导入** | `FAN-0012` | 写了设备表里没有的编号（外键悬空） |
| point_code | 是 | 2-48 位大写字母/数字/下划线；全表唯一 | `FAN0012_VIB` | 用中文（如 `FAN0012_振动`）——编码必须 ASCII，中文名放 point_name |
| point_name | 是 | 1-64 字符 | `轴承温度` | 空着 |
| point_type | 是 | 12 选 1：温度/压力/振动/转速/电流/电压/流量/液位/位移/噪声/湿度/功率 | `振动` | 写"加速度"等枚举外的值 |
| unit | 是 | 1-16 字符 | `mm/s` | 空着 |

---

## 四、提交前自查 5 条

1. 两个 sheet 名、表头行**一字不差**
2. 编号全大写、格式正确、不重复
3. 测点的 device_code 在设备表里**存在或同批导入**
4. 枚举列（类型/状态）从白名单里选，不要手打
5. 必填列没有空格占位（系统会去首尾空格，但纯空格仍算缺失）

## 五、导入怎么走（推荐先预检）

| 步骤 | 操作 | 说明 |
|---|---|---|
| 1（推荐） | `POST /api/import/validate`（在 `/docs` 页面点 Try it out 上传） | **只校验不写库**，先看有没有问题 |
| 2 | `POST /api/import/excel` 或 Web 首页导入页上传 | 正式导入 |
| 3 | 看返回的打回单 / 评分报告 | 见下节 |

**单次上限 200000 行**（`config/app.yaml` 的 `import.max_rows`），超了先拆文件。

## 六、打回单怎么读

校验失败时**一条都不会写入数据库**（整批原子），返回的打回单每条问题包含：

| 字段 | 含义 |
|---|---|
| row | **Excel 实际行号（表头算第 1 行）**——直接去 Excel 改这一行 |
| column | 出错的列名 |
| rule | 规则类型：`required`/`regex`/`enum`/`unique`/`foreign_key` 等 |
| message | 人话说明，含你当前的值 |

**重要**：有些行分数够高也可能被打回——必填缺失、编号重复、外键悬空是**结构性错误，一票否决**，不能靠其他列的满分抵消（`validator.py` 的 `FATAL_RULES`，阈值见 `rules.yaml` 的 `pass_threshold: 85`）。

## 七、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 提示"表头不匹配" | sheet 名或列名改过 | 照第二、三节的表原样恢复 |
| 90 分仍被打回 | 存在结构性错误 | 打回单里 rule 是 `required`/`unique`/`foreign_key` 的行必须改 |
| 想调整必填项/格式/阈值 | 规则全部在 `config/rules.yaml` | 找 C2（校验规则负责人）改配置，不改代码；模板说明会同步更新 |
| 中文编码过不了 | point_code 只允许 ASCII | 中文写进 point_name，编码用英文缩写（如 `VIB`/`TEMP`） |
