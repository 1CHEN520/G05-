## 四、风险登记与处置（计划时识别 → 实际结果）

| 风险 | 计划处置 | 实际结果 |
|---|---|---|

| 契约冲突返工 | M1 冻结 DTO/错误码 | 评审零返工 |

## 五、变更管理

- 所有变更走 issue + 本人 PR（归属清单先查后改），main 禁止直推；
- 契约变更须评审裁定并留痕（docs/review）；实测数据变更须同步基线 JSON 与矩阵；
- 进度变更（里程碑偏移）在周例会登记并更新本文档第四节。

## 六、进度核查命令（阅卷可复现）

```bash
git shortlog -sn                      # 贡献统计
gh pr list --state merged --limit 90  # PR 总账
git log --oneline --since="2026-11-01" --until="2026-11-17"  # 周期校验
```
